     python3 server_http.py --transport http --host 127.0.0.1 --port 8000
   
   Client Connection:
     http://127.0.0.1:8000
   
   Use Case:
     Local development, testing

2. PRODUCTION ON VPS/HOME SERVER (15 minutes)
   ─────────────────────────────────────────
   Option A: Systemd
     sudo cp dse-mcp.service /etc/systemd/system/
     sudo systemctl enable dse-mcp
     sudo systemctl start dse-mcp
   
   Option B: Docker Compose
     docker-compose up -d
   
   Client Connection:
     http://<server-ip>:8000
   
   Use Case:
     Production, auto-restart, monitoring

3. PRODUCTION WITH HTTPS (30 minutes)
   ───────────────────────────────────
   Setup:
     - Install Nginx
     - Configure nginx-dse-mcp.conf
     - Get SSL cert (Let's Encrypt via Certbot)
   
   Client Connection:
     https://dse-mcp.example.com
   
   Use Case:
     Secure remote access, domain-based
